Scuola Italiana
Baku · Italy

A full-featured informational and course platform built for Scuola Italiana Baku — the city's premier Italian language school and cultural centre. The site supports three languages, a detailed course directory, exam preparation resources, and a live search across all content. Deployed as a static export for zero-latency page loads worldwide.

Trilingual Interface

Full AZ / EN / IT support with a spring-animated language switcher and instant translation swap.

Dark Mode

System-aware dark/light mode via next-themes, persisted in localStorage, smooth transitions.

Static Export

Pre-rendered HTML from Next.js — served from CDN with no server required, sub-100ms TTFB.

CEFR Course Structure

A1–C2 aligned curriculum with group and private lesson formats, CILS & CELI exam prep tracks.

Live Content Search

Client-side full-text search across courses, culture pages, and events — no backend required.

Multi-Page Architecture

7 distinct pages: Home, About, Courses, Café, Lingua, Cultura, Contacts — all with SEO meta.

Next.js 14 SSG TypeScript strict mode Tailwind CSS 3.4 react-hook-form Headless UI dropdowns Custom IntersectionObserver hook
